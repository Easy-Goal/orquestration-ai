# AGENTS.md — orquestration-ai

Instruções de projeto para qualquer agente de IA (Cursor, Windsurf, Codex, etc.)
trabalhando neste repositório.

## Sobre este projeto

- Repositório de conhecimento consolidado do ecossistema Easy Goal — só Markdown,
  sem código de produto.
- Ponto de entrada para qualquer um chegando de outro projeto: `knowledge/00-ecosystem-overview.md`.
- Ponto de entrada para quem vai editar este repo: `README.md` + `CLAUDE.md`.

## Terminologia

- **📌 Fixo — já em produção**: fato verificado, não é uma escolha do projeto que
  consome este repo. Não propor alternativa sem evidência de que o fato mudou.
- **🔧 Padrão de referência — decidir por projeto**: existe um exemplo validado em
  produção, mas a decisão final é do escopo/marca/stack de cada projeto novo.

## Preferências de estilo

- Português do Brasil em todo o conteúdo.
- Tabelas para comparação de opções; blocos de código para exemplos de
  implementação; nunca prosa longa onde uma tabela é mais clara.
- Toda regra em 📌 deve citar a fonte (doc pública ou repo real) no cabeçalho do
  arquivo.

## Limites de conteúdo

- Não incluir segredos, chaves reais ou IDs de projeto Supabase específicos.
- Não duplicar o workspace de tracking de tarefas do `easy-labs` (active.md,
  kanban, roadmap) — este repo é conhecimento estável entre projetos, não estado
  de um projeto específico.
